# うちの条件・使い方を起点にした比較

## 公開画面の追加監査

日用品版の公開トップで、店頭価格500円・12ロールを入力し、楽天掲載候補との単価判定が即座に出る操作を確認した。検索・同一商品照合・価格判定が入口で、月の使用量も店頭価格差の換算に従属する。

ペット版の公開PC・390×844表示では、最安・中央値の価格がカテゴリ入口の主役だった。猫砂は素材を混ぜた「すべて」が初期表示で、サイズや本体も利用者が答える前に初期条件が選ばれていた。使用環境の設定と、商品の価格差が別の意味として見えにくい。

## 組み直した体験

- トップは「何を使っていますか？」。犬・猫の用途、次に答える質問、選択肢を示す。今日の価格差と店頭判定を主入口にしない。
- 初回の比較画面は、使っているサイズ・素材・トイレを選んでから結果を開く。価格比較に使用量入力を要求しない。
- 猫砂の紙・おから・木・鉱物を先に表示。混合素材・用途・素材不明・素材指定なしは別の開閉欄で正確な既存分類を維持する。
- 条件と使用量を端末に保存。復元しても計測イベントを増やさず、消えた条件は勝手に別の条件へ置き換えない。
- 使用量から、各候補の持つ期間と30日分の費用へ変換。買い方の3候補は共通尺度の期間バーでも比べる。
- 単価・今回の出費・数量・持つ期間をつなぐ。品質のおすすめや交換頻度の推奨を行わない。
- 店頭比較は、うちの条件の商品を店で見つけたときの補助として下部に残す。

## 計算と表示

購入数量 / 使用量 / 使用期間をそのまま使い、毎日の使用量なら日数、週なら週間、月ならか月で表示。月の費用は30日へ統一する。800枚・3,280円・日5枚は160日分 / 615円、42L・2,499円・月10Lは4.2か月分 / 約595円、20枚・1,750円・週1枚は20週間分 / 30日約375円。送料別の送料は未加算と表示する。

入力の空欄・解除では生活換算を表示しない。0・負数・指数表記・不正なカンマは拒否し、以前の使用量の結果を残さない。全角数字・小数に対応。初回入力から結果は即時更新し、GA4は確定操作で送信する。

既存の取得・単価・数量・分類・重複排除・品質判定・Secrets・SEO・Pages競合対策・更新スケジュールは維持。GA4の既存イベントはすべて残し、カテゴリ入口と使用量反映の2イベントを追加した。使用量の数値は新イベントへ含めない。
