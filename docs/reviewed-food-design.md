# ごはんの比較・第2段階（2026-10-01）

## 監査と設計

公開版は犬猫のごはんへ進めるが、袋の計算機と掲載保留の説明で終わる。プロフィールと計算機の値も候補選びにつながっていない。既存の犬猫入口、イラスト、任意保存、消耗品比較は維持する。

今回の順序は年齢 → いつもの銘柄・対象条件の確認 → 買い方 → 袋の候補。異なるレシピを単価だけでおすすめすることを避け、同じメーカー製品ファミリー内の容量・袋数を比較する。初期表示では価格の答えを出さない。プロフィールの年齢・犬の体格が変われば候補も再照合し、不一致では表示しない。

1日量は任意。ユーザーが入力したg/日から候補ごとの日数と30日費用を計算する。体重・犬種から給与量は推定しない。期間は数量の換算であり、開封後の保存可能日数ではない。従来の自由入力計算機は補助機能として残す。

## 掲載ゲート

メーカー公式ページと個別楽天販売ページを照合したURLだけを許可する。製品名、年齢、食種、栄養区分、単袋容量、袋数、合計量、対象条件を記録。タイトルの必須語・数量・年齢が変わる、未承認URL、レビュー期限180日超過、療法食・用途限定品・選択式は掲載しない。取得価格やアフィリエイトURLを手作業で捏造しない。取得失敗時は候補なしにする。

最初のファミリーは犬「ミニ アダルト」、猫「フィット」。犬は小型成犬、猫は成猫の製品。シニア・幼齢の候補は未確認のため出さない。猫の旧パッケージは年齢上限が異なるため、メーカーと販売店双方の表記確認を求める。病気・アレルギーへの適合や品質順位は提供しない。

## 実取得で判明した点

通常の各30件検索では照合済み店舗が結果外になる。取得処理の既存パラメータは維持し、照合済み店舗に限って `shopCode` を追加指定して取得する。メーカー・URL・タイトル・数量の掲載ゲートは同じ。公式API根拠：https://webservice.rakuten.co.jp/documentation/ichiba-item-search 。既存呼び出しとのリクエスト・アフィリエイト契約の互換性をモックで検証する。
