# うちの子から始まる用品選び — 実装前設計

## UX監査
入口はトイレ消耗品3種。犬猫、年齢、遊び方を起点に選べず、使える条件から始める思想がサイト全体の探索には広がっていない。比較結果・TOP3・買い方・使用量・店頭計算は再利用する。猫砂の素材を問わない表示は価格感を知る参考モード。
現在の care_art は前回の正式WebPを使用し簡易SVGではない。操作用 icon は線画SVG。世界観と選択入口は新規制作し、素材差を説明する既存の正式図版は維持する。

## 画面構造
トップ：暮らしの主画像→犬／猫→用品→必要な条件→既存比較または遊び方による発見。既存3用品への直接経路も残す。
犬：ごはん／シーツ／おもちゃ。猫：ごはん／猫砂／システムトイレ／おもちゃ。
プロフィールは犬猫別の年齢段階、犬の現在の体格、体重、犬種猫種（任意）。体重・犬種から給与量・適合を推測しない。端末保存は任意、読み書き不能でも利用可能。体重・犬種・使用量をGA4へ送信しない。

## 安全性と段階
フードは一般ドライ総合栄養食・犬猫・年齢・重量を明確に確認する。療法食、疾病・治療目的、スナック、選択式容量、定期便、中古、訳あり等は除外。SEOキーワードだけで適合を確定しない。犬猫とも取得結果の分類調査を非公開で行い、承認商品台帳ができるまで価格ランキングは公開しない。袋重量・価格・入力1日量による計算は公開可能。体重から独自推定しない。
おもちゃは犬猫・遊びタイプ・サイズの表記、URL、価格を根拠として保管。推測属性・価格順位なし。矛盾・選択式は保留。年齢・体格指定時は明記のない候補を適合済み扱いにしない。見守り・誤飲・破損・紐羽小部品の注意を表示する。
新領域は既存3カテゴリと分離したconfig・分類・根拠・監査を持つ。未確認商品を仮掲載しない。
