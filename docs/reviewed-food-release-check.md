# ごはんを「いつもの銘柄・うちの使い方」で比較する公開確認

確認日：2026-10-02 JST（照合記録は2026-10-01 UTC）。

## 監査と設計

犬猫から選ぶ入口、任意プロフィール、既存3用品、使用量、用品選択の上質なイラストは再利用した。フードは入力計算だけで商品候補に進めなかったため、年齢→犬は体格→確認済みのいつもの銘柄→袋の買い方へ進む構成を追加した。日用品版の市場価格判定とは異なり、確認済みの適合条件と暮らしの使用量が先にある。

## 公開範囲

- 犬：ロイヤルカナン ミニ アダルト、小型成犬向け。800g・2kgの1袋商品を取得・掲載。8kgは照合済みだが今回のAPI取得結果に含まれず未掲載。
- 猫：ロイヤルカナン フィット、成猫向け。2kg・4kgの1袋商品を取得・掲載。
- 比較は同じ銘柄の掲載候補内。100g・1kg単価、商品総額、袋容量、任意の1日量による日数・1日費用・30日換算を表示する。
- 「長く使って安く」「今日は出費を抑える」「買い足す回数を減らす」で表示順と理由を更新。
- 未照合の銘柄・幼齢・シニア、療法食、曖昧な数量、異なる形態・栄養区分、選択式商品は公開しない。体重・犬種から給与量を推定しない。対象年齢、原材料、新旧パッケージ、開封後保存方法は購入前確認を促す。
- 銘柄・条件・使用量の保存は任意。端末保存の拒否・破損・削除でも利用できる。

## 維持した機能とアート

既存3用品の条件別比較、TOP3、中央値差、3つの買い方、店頭比較、使用量、アフィリエイトURL、分類・数量解析・品質監査を維持した。取得処理は省略可能な店舗検索引数だけを追加し、Secrets、API契約、SEO、GA4既存イベント、自動更新、Pages公開競合対策は維持した。

今フェーズでは画像を追加していない。前フェーズの生成り・セージ・自然光・ガッシュ質感の28点WebP（合計767,300B）を継続使用。`care_art()`は用品・素材の既存画像を描画し、世界観の新しいSVG図形は作らない。操作記号の`icon()`は線画SVGのまま。犬種・猫種は任意のプロフィール情報で、商品推薦の根拠にはしない。

## 確認結果

- Python39件、DOM20件、合計59件成功。全13用品フィルター、TOP3・固定サマリー・理由・店頭比較・使用量、GA4既存イベント、reduced motionも回帰テストで確認。
- 公開PCと390×844 CSS幅で犬猫の年齢・体格→銘柄→袋比較を操作。スマホはChromeのiframeによる幅確認で、実機Safariの確認ではない。
- 猫60g/日：2kg約33.3日・30日約3,280円、4kg約66.7日・30日約2,914円。犬120g/日：800g約6.7日・30日約7,083円、2kg約16.7日・30日約5,854円。給与量の推薦ではなく検証入力。
- 買い方切替、条件・使用量の保存と再読み込み、保存削除、入力制限・不適合条件での候補非表示を確認。保存後の案内文も修正。
- 楽天リンクから猫4kgの実商品ページへ遷移し、対象商品・価格・アフィリエイト遷移を確認。
- 品質監査成功。69件：既存用品63、犬猫のおもちゃ各1、犬猫フード各2。
- PR38〜41のCI、公開ビルド、GitHub Pages成功。PR41公開ビルド36934852006、Pages36934964015。
- GA4の新規5イベント：pet_food_condition_select、pet_food_family_select、pet_food_buying_select、pet_food_usage_set、pet_food_preferences_clear。使用量・体重・犬種文字列は送信しない。タグ・イベント発火はコード／DOMテストで確認、GA4管理画面の受信集計は未確認。
